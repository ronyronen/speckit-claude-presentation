# The vague prompt

This is the exact prompt used to produce `naive_monitor.ino`, with no
follow-up questions and no specification step:

```text
Build an application for a Heltec WiFi Kit V3 that reads a sensor,
shows the value on the display, and shows a warning when the value is too high.
```

Nothing else was said. The AI agent had to invent every decision below on
its own, silently, because the prompt did not make them.
